# Portfolio Profesional - Sergio Díaz de Rivera Anta

Portfolio web personal desarrollado como escaparate para mostrar mi perfil técnico, formación académica, experiencia laboral y proyectos de desarrollo.

## 🛠️ Tecnologías Utilizadas
- **HTML5** (Estructura semántica modular)
- **CSS3** (Diseño adaptable, variables CSS y tematización Dark Tech)
- **JavaScript** (Gestión de vistas dinámicas SPA y interactividad)

## 📂 Contenido del Portfolio
- **Sobre mí:** Perfil personal y objetivos profesionales.
- **Competencias Técnicas:** Tecnologías dominadas (Java, Python, MySQL, Git, etc.).
- **Proyectos:** Casos de estudio detallados, incluyendo *HotelApp* (Desarrollo de Interfaces con JavaFX y FXML).
- **Experiencia Laboral:** Prácticas profesionales (prosr4pro y BCD Electro).
- **Formación Académica:** Grado Superior en DAM, Grado Medio en SMR e Inglés C1 Cambridge.
