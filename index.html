HotelApp - Sistema de Reservas

Proyecto práctico de interfaz JavaFX y FXML conectado a datos XML.

Autor: Sergio Díaz de Rivera Anta Fecha: Octubre 2026

Momento 1: Estructura y Arquitectura del Proyecto

La aplicación está estructurada en Java utilizando Maven (`pom.xml`). Los archivos principales son:

  • Main.java: Punto de entrada principal que inicializa la aplicación JavaFX y carga la escena inicial.
  • Controllers/DatosController.java: Controlador encargado de gestionar la lógica de negocio, procesar el archivo XML y manejar las interacciones del usuario.
  • resources/vista.fxml: Fichero FXML que define el diseño visual de la interfaz de usuario.
  • resources/reservas.xml: Base de datos ligera en formato XML que almacena las habitaciones y el estado de sus reservas.

Momento 2: Interfaz y Lógica de Búsqueda

Al introducir un número de habitación en el campo de texto y pulsar el botón «Buscar», el controlador consulta el archivo XML para verificar el estado de dicha habitación. Dependiendo del resultado, la interfaz actualiza un componente Label mostrando de forma dinámica si está Disponible, Ocupada o si No existe.

Resultados de Pruebas Obligatorias

Prueba / Estado Dato Introducido Resultado Esperado Resultado Obtenido ¿Correcta?
1. Disponible N.º: 130 Indica disponible Número de habitación: 130 - Habitación disponible Sí

3. No existe N.º: 150 Indica que no existe Número de habitación: 150 - La habitación no existe Sí

Momento 3: Propuesta de Mejora (Gestos y Realidad Aumentada)

Mientras que la Parte 1 implementa una interfaz básica textual de ocupación leída desde XML, la propuesta de mejora para la Parte 2 en grupo consiste en integrar el tema asignado de Gestos y Realidad Aumentada.

Se proyecta desarrollar una vista visual interactiva en 360° de las habitaciones dependiendo de su capacidad y tipología (habitaciones premium con dos camas, etc.), manteniendo la sólida base de búsqueda por número ya programada en esta primera fase.
